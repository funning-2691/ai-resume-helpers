## 1. 产品简介

AI简历助手是一个基于大模型的简历优化工具，帮助用户：
- 针对目标岗位优化简历内容的表达
- 查看简历对岗位关键词的覆盖率
- 在本地浏览器保存历史优化记录

---

## 2. 快速上手（首次使用）

| 步骤 | 操作 | 说明 |
| :--- | :--- | :--- |
| 1 | 打开本地运行地址 | 本地运行默认 http://localhost:3000 |
| 2 | 准备岗位描述和简历 | 可以是文本或文件（.txt/.docx） |
| 3 | 填写/上传内容 | 参考第3节详细说明 |
| 4 | 点击"开始优化" | 等待 AI 返回结果 |

## 3. 核心任务

### 3.1 如何优化简历

**前置条件**：已准备好岗位描述（JD）和个人简历的文本或文件。

**操作步骤**：

| 步骤 | 动作 | 说明 |
| :--- | :--- | :--- |
| 1 | 输入岗位描述 | 粘贴到页面左上方文本框，或点击"上传JD"按钮上传文件 |
| 2 | 输入个人简历 | 粘贴到页面左下方文本框，或点击"上传简历"按钮上传文件 |
| 3 | 设置优化方向（可选） | 选择"优化强度"，可勾选"匹配关键词高亮" |
| 4 | 开始优化 | 点击页面右上角 **"开始优化"** 按钮 |
| 5 | 等待处理 | 系统显示"优化中"加载状态 |
| 6 | 查看结果 | 右侧区域展示关键词覆盖率和 AI 优化后的简历内容 |

**预期结果**：
- 页面右侧显示 **岗位关键词覆盖率**（0-100%）与进度条。
- 如果 JD 中无法识别到可计算的关键词，覆盖率区域显示 **"暂无可计算关键词"**。
- 优化结果上方显示提示：**"AI 生成结果仅供参考，请人工核对后再投递使用。"**
- 优化结果会在成功后自动保存到当前浏览器的历史记录。

### 3.2 如何保存优化结果

**操作步骤**：
1. 在优化结果区域，点击 **"复制"** 按钮 → 可粘贴到 Word/其他编辑器
2. 点击 **"下载"** 按钮 → 选择 **TXT** 或 **Word** 格式保存到本地

### 3.3 如何查看历史记录

**操作步骤**：
1. 点击页面右上角 **"历史记录"** 按钮
2. 系统展示历史优化列表（按时间倒序，最多 10 条）
3. 点击任意一条记录，可查看完整内容和覆盖率
4. 可对单条记录执行删除，或点击"清空全部"清空所有记录

**重要说明**：
- 历史记录仅保存在**当前浏览器**的 localStorage 中。
- 清除浏览器数据、切换设备或浏览器后，记录无法恢复。
- 历史记录中无关键词的岗位会显示"暂无可计算关键词"。
- 请勿在公共设备上保存涉及敏感信息的简历。

## 4. 常见问题（FAQ）

| 问题 | 解答 |
| :--- | :--- |
| 优化结果不满意怎么办？ | 可修改原文后再次点击优化。由于 AI 的随机性，每次结果可能略有不同，多试几次可获得满意版本。 |
| 覆盖率为什么是 0%？ | 覆盖率 = 简历中命中的 JD 关键词数 ÷ JD 关键词总数。0% 表示简历文字中没有命中任何已识别出的 JD 关键词。 |
| 为什么显示"暂无可计算关键词"？ | 说明当前 JD 中没有识别到预置关键词库中的任何词，因此无法计算覆盖率。这不代表 JD 本身有问题。 |
| 覆盖率 100% 代表什么？ | 只代表简历文字覆盖了所有已识别的 JD 关键词，不代表胜任该岗位或能获得面试机会。请务必结合岗位实际要求人工判断。 |
| 上传文件失败？ | 当前支持 **.txt** 和 **.docx** 格式。如仍失败，请尝试直接粘贴文本。 |
| 历史记录能保存多久？ | 保存于当前浏览器 localStorage，直到浏览器数据被清除。跨设备/浏览器不同步。 |
